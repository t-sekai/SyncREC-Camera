# Device Setup Guide
This guide is mainly for setting up new iPhones into the rig.

1. Set up wifi on the same network as the other iPhones and the director.
2. Turn off software update.
3. Enable guided access mode in accessibility settings.
4. Download the app from TestFlight or App Store when it's available.
5. Set unique device name and director server in app.

Strong advices:
* Name your devices in numbers (1-10) or alphabets (A-Z), and set your device background with the name for easy recognition when you have many devices.
* In guided access mode, set auto-lock to 30 seconds, so the phones can sleep faster once you finish upload and turn off always awake.
* Turn off airdrop by bringing devices together.
